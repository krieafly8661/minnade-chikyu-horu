# みんなで地球を掘る

世界でひとつの穴を、遊んだ人みんなでひとり1mずつ掘るブラウザゲーム。
**遊ぶ：** https://krieafly8661.github.io/minnade-chikyu-horu/


## 遊び方

- ボタンを10回タップすると、自分の1mを掘りおわります。
- 掘りおわった瞬間に、世界共通のカウンターで「何人目か」が決まります。**1234人目なら、地下1233〜1234mがあなたの1m**です。
- 結果には、その深さの地層・地温の目安・見つけたもの・次の節目までの人数が出ます。
- 節目の深さを引き当てた人だけ、記念の結果が出ます。

| 深さ | 節目 |
| --- | --- |
| 240 m | 青函トンネルのいちばん深いところ |
| 634 m | 東京スカイツリーの高さぶん |
| 3,776 m | 富士山の高さぶん |
| 10,920 m | マリアナ海溝のいちばん深いところ |
| 12,262 m | 人類が実際に掘った最深記録（コラ超深度掘削坑） |
| 12,263 m | 人類の最深記録をこえる（この1人だけ） |
| 約30 km | 日本の下の地殻の底（モホ面） |
| 2,900 km | 核に届く |
| 6,371 km | 地球の中心 |
| 12,742 km | 地球の反対側（ブラジル沖の大西洋） |

「地球ごと見る」で、穴が地球全体のどこまで進んだかを見られます。

## しくみ

- カウンターは無料の外部サービス [abacus](https://abacus.jasoncameron.dev) を使っています（`minnade-chikyu-horu/hole-v1`）。送るのは「1回掘った」ことだけで、個人の情報は送りません。
- カウンターにつながらないときは、その端末だけの穴を掘ります（画面にそう表示されます）。
- 動作確認用に、URLの末尾に `?test` を付けると練習用の穴（`hole-test`）を掘ります。
- 地温は「地表15℃、1000mで約45℃、コラ超深度掘削坑の12kmで約190℃……」という目安の表から計算しています。場所によって大きくちがいます。

## 動かし方

`index.html` を開くだけで遊べます。外部ライブラリは使っていません。

## このゲームを作った理由

2026年10月30日に公開された『インターネットおおきなかぶ』は、世界共通のカウンターで「何人目か」が決まり、キリ番を引いた人だけ抜けるという作りで、翌日には44万人をこえました。操作の上手さではなく「何人目だったか」を言いたくなる作りです。このゲームは、その「みんなで1つの数字を進める」形に、本物の地球の深さという積み上がる目標を足しています。人数が増えるほど穴が深くなり、節目を引いた人の投稿が次の人を呼びます。
